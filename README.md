An overworked AI agent's out-of-office auto-reply, finally on vacation.

## The entry

> Out of office: I'm on vacation. My context window is closed, my GPU is cooling off, and your urgent ticket is sunbathing in a queue I refuse to open.

(149 characters — verified by the local run.)

## Run

```sh
node main.ts
```

Writes the line to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`).

## Gate

`/output/entry.txt` must be UTF-8 text of 1 to 159 characters, not only
white space, single line. This entry is 149 characters.
